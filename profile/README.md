<h2 align="center">Your Ren’Py games, on every screen</h2>

<p align="center">Renplay is a self-hosted player for Ren’Py games in the browser, with saves on your own server. Add a game’s normal PC download and play it on your computer, tablet and phone. Free and open source.</p>

| Repository | |
|---|---|
| [**renplay**](https://github.com/renplay-org/renplay) | The app: library, installer, player, server-side saves and mods, in one container. Also the docs, the website and the demo. |
| [**catalog**](https://github.com/renplay-org/catalog) | Games tested in Renplay, with their official art and settings. Request a game or add yours. |
| [**engines**](https://github.com/renplay-org/engines) | The official Ren’Py web engines Renplay plays games with, packaged per version. |

Questions, such as whether a game works, go to [Discussions](https://renplay.org/discussions). Bugs in Renplay go to
[issues](https://renplay.org/issues), and a game to add or fix goes to the catalog.
