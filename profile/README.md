<h3 align="center">Ren’Py games in the browser, self-hosted</h3>

<p align="center">Drop in a game’s PC download. Renplay builds it for the web, plays it on any device, including phones, and keeps your saves on your server.</p>

| | |
|---|---|
| [**Renplay**](https://github.com/renplay-web/renplay) | The app: library, installer, player, server-side saves, mods |
| [**Catalog**](https://github.com/renplay-web/catalog) | Curated recipes and covers for games known to work, and how to add one |
| [**Engines**](https://github.com/renplay-web/engines) | Official Ren’Py web engines, packaged per version |
